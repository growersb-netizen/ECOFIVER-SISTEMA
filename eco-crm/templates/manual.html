Roles y permisos
Quién puede hacer qué en el sistema
Cada usuario tiene uno o más roles que determinan a qué módulos puede acceder y qué acciones puede realizar. El menú lateral y el dashboard se adaptan automáticamente al rol del usuario que inicia sesión.
Rol Responsabilidad Módulos accesibles
ADMIN Acceso total al sistema Todos los módulos sin excepción
ASESOR_APERTURA Asesor comercial de captación / primera venta Dashboard, Leads, Videollamadas, Ventas Contado, Ventas Financiadas
SUPERVISOR_CIERRE Supervisor de cierre de ventas Dashboard, Videollamadas (con asignación de supervisor), Ventas Financiadas
COBRANZAS Gestión de cobros de cuotas Dashboard, Cobranzas
FABRICA Operaciones de fabricación Dashboard, Fábrica, Producción, Materiales, Personal
COORDINADOR_OPERATIVO Coordinación general de operaciones Fábrica, Producción, Materiales, Logística, Coord. Entregas, Contratos, Personal, Flota, Importar, Ecopost, MercadoLibre, Web CMS, Configuración, Usuarios
ADMINISTRACION Administración y sueldos Dashboard, Fábrica, Materiales, Personal (asistencia + liquidación)
💡 Tip: Un usuario puede tener múltiples roles simultáneamente. Zapia (usuario de automatizaciones) tiene todos los roles activados para poder operar en cualquier área del sistema.
🏠
Dashboard
Vista de resumen y acceso rápido
📊 Tarjetas de métricas (KPIs)
Al ingresar al sistema, el Dashboard muestra las métricas más importantes del día y del mes, adaptadas al rol del usuario. Cada tarjeta muestra un número clave y al hacer clic lleva directamente a la lista filtrada de esos registros.
Métricas por rol:
• ADMIN: Leads hoy, Videollamadas hoy, Ventas del mes, Cuotas vencidas, Órdenes en fábrica, Presentes hoy.
• ASESOR: Mis leads activos, VL agendadas, Cierres del mes, Leads sin contactar +48h.
• SUPERVISOR: VL sin supervisor, VL de hoy, Cierres del mes.
• COORDINADOR: Instalaciones hoy, Instalaciones mañana, Órdenes terminadas, Reclamos abiertos.
• COBRANZAS: Cuotas que vencen hoy, Cuotas vencidas, Gestiones del día, Pagos del mes.
• FÁBRICA/ADMIN: Órdenes activas, Stock bajo, Presentes hoy, Liquidación pendiente.
💡 Tip: Hacé clic en cualquier tarjeta para ir directamente a la lista de esos registros con el filtro ya aplicado. Por ejemplo, clic en "Cuotas vencidas → 5" te lleva a Cobranzas mostrando solo las 5 cuotas vencidas.

Leads
Gestión de prospectos y pipeline de ventas
➕ Crear lead manualmente
Permite registrar un prospecto nuevo que contactó por WhatsApp, Instagram, web o referido. Se registra nombre, teléfono, localidad, producto de interés, forma de pago y origen.
Cómo: Botón "+ Nuevo lead" arriba a la derecha → completar el formulario → Guardar.
📋 Vista Lista y Vista Kanban
Los leads pueden verse en dos formatos: Lista (tabla con todos los datos) o Kanban (columnas por estado, ideal para ver el pipeline de ventas de un vistazo). Se puede arrastrar leads entre columnas en la vista Kanban.
Cómo: Botones "≡ Lista" y "⊞ Kanban" arriba a la derecha de la pantalla.
🔍 Filtros avanzados
Se pueden filtrar leads por estado (Nuevo, Contactado, Calificado, VL Agendada, Cerrado, Perdido), producto (Piscina, Módulo, Combo), forma de pago (PMI, Directa 50%, Contado) y origen (WhatsApp, Instagram, Web, Referido). También hay búsqueda por nombre o teléfono.
📱 Contacto directo por WhatsApp
Desde cada lead hay un botón directo para abrir WhatsApp con el número del prospecto y un mensaje pre-cargado. Facilita el primer contacto sin tener que copiar el número manualmente.
Cómo: Hacer clic en el botón verde 📱 WhatsApp dentro del detalle del lead.
✏️ Editar lead y cambiar estado
Permite actualizar todos los datos del lead, incluyendo mover su estado en el pipeline. Los estados marcan el avance: Nuevo → Contactado → Calificado → VL Agendada → Cerrado / Perdido.
Cómo: Hacer clic sobre el lead en la tabla → se abre el modal de detalle → editar campos → Guardar.
📥 Importar leads desde Excel / CSV
Permite cargar una planilla con cientos de prospectos de una vez. El sistema los distribuye automáticamente entre los asesores de forma equitativa (round-robin por carga activa).
Cómo: Botón "📥 Importar" → seleccionar archivo Excel/CSV → el sistema muestra una vista previa → confirmar importación.
Columnas soportadas: nombre*, telefono*, localidad, producto, modelo, forma_pago, origen, notas
💡 Tip: Podés descargar el template desde Importar → pestaña "Leads" → "Descargar template Excel".
🔀 Reasignar leads (ADMIN)
Permite reasignar uno o varios leads a otro asesor. Útil cuando un vendedor deja la empresa o cuando hay un desbalance de carga entre asesores.
Cómo: Tildar las casillas de selección → botón "🔀 Reasignar" → elegir asesor destino.
Para mover todos los leads de un vendedor: botón "⚡ Transferir".
⚠️ Alerta leads sin contactar +48h
El sistema detecta automáticamente los leads nuevos que llevan más de 48 horas sin ser contactados y los resalta con una alerta amarilla en la parte superior. Ayuda a no perder prospectos por falta de seguimiento.

Videollamadas
Agenda y seguimiento de VL de ventas
➕ Agendar videollamada
Registra una videollamada de cierre de ventas con datos del cliente, fecha y hora, asesor de apertura, supervisor de cierre asignado, forma de pago (PMI / Directa 50%) y producto de interés.
Cómo: Botón "+ Nueva VL" → completar formulario → Guardar.
📅 Vista "Hoy"
Muestra únicamente las videollamadas agendadas para el día de hoy en formato de tarjetas, con botón de WhatsApp para contactar al cliente antes de la llamada.
Cómo: Pestaña "📅 Hoy" en la parte superior de la pantalla.
🔁 Actualizar estado y resultado
Después de cada VL se debe registrar su resultado: Pendiente, Avanzó, No calificó, Cerró. También el estado de la llamada en sí: Agendada, Realizada, No se presentó, Reprogramar. Estos datos alimentan las métricas del dashboard.
🔍 Filtro "Sin supervisor"
Muestra solo las VL que aún no tienen un supervisor de cierre asignado. Permite al coordinador o supervisor asignarse a las llamadas pendientes rápidamente.
Cómo: Tildar el checkbox "Sin supervisor" en la barra de filtros.
💰 Comisiones asesor y supervisor
En cada VL se puede registrar el porcentaje de comisión correspondiente al asesor de apertura y al supervisor de cierre. Sirve para calcular comisiones al momento de la liquidación.
📋 Estado de admisión PMI
Para ventas financiadas bajo el plan PMI, se puede registrar el estado de la solicitud de crédito: Postulado → En revisión → Aprobado / Rechazado.

Ventas Contado
Registro de ventas pagadas al contado
➕ Registrar venta contado
Carga una venta cerrada en efectivo o transferencia total. Se registran: cliente, teléfono, localidad, producto, modelo, color, precio de venta, flete, fecha de instalación y vendedor responsable.
Cómo: Botón "+ Nueva venta" → completar datos → Guardar.
🔄 Seguimiento de estado
Cada venta contado pasa por 3 estados: Coordinado (fecha acordada con el cliente), Instalado (entrega realizada) y Cobrado (pago confirmado).
Cómo: Hacer clic en el botón de estado dentro de cada fila de la tabla.
🔍 Búsqueda y filtros
Se puede buscar por nombre de cliente y filtrar por estado (Coordinado, Instalado, Cobrado) para ver en qué etapa está cada venta.
📋
Ventas Financiadas
Planes de cuotas PMI y Directa 50%
➕ Registrar venta financiada
Carga una venta cerrada en cuotas. Se registra: forma de pago (PMI o Directa 50%), producto, modelo, precio base, cantidad de cuotas, monto por cuota, fecha de la primera cuota y asesor. El sistema calcula el cronograma de vencimientos automáticamente.
Cómo: Botón "+ Nueva financiada" → completar formulario → Guardar.
📊 Seguimiento del plan de cuotas
Muestra el estado de cada plan: cuántas cuotas pagó el cliente, cuánto debe, cuándo vence la próxima cuota y si tiene atraso. Esta información es la base de Cobranzas.
🔍 Filtros
Se puede filtrar por estado del plan (Activo, Atrasado, Cancelado, Finalizado), forma de pago (PMI / Directa 50%) y activar el filtro "Solo con atraso" para ver los clientes que no están al día.
💳
Cobranzas
Seguimiento y gestión de cobro de cuotas
📋 Cartera activa
Muestra todos los clientes con cuotas activas. Cada tarjeta indica el nombre del cliente, producto, localidad, días de atraso (si tiene), cuota próxima y avance del plan (barra de progreso). Las tarjetas se colorean automáticamente: rojo = en atraso, amarillo = vence en 3 días, verde = al día.
⚠️ Tarjetas de estadísticas con filtro instantáneo
Las tarjetas de resumen en la parte superior muestran: Cuotas que vencen hoy, Cuotas vencidas, Gestiones del día, Pagos del mes. Al hacer clic en "Vencen hoy" o "Cuotas vencidas" la lista se filtra automáticamente mostrando solo esos clientes.
💡 Tip: Hacé clic nuevamente en la misma tarjeta para quitar el filtro y ver la cartera completa.
📱 Contacto WhatsApp con mensaje automático
Desde cada tarjeta hay un botón de WhatsApp que abre una conversación con el cliente con un mensaje pre-cargado indicando el monto y la fecha de vencimiento de su cuota. Ahorra tiempo al equipo de cobranzas.
📝 Registrar gestión de cobranza
Permite registrar cada contacto realizado con el cliente moroso: por qué canal se contactó (WhatsApp, Llamada, Presencial), cuál fue el resultado (Prometió pagar, Pagó, No contestó, Reclama, Acuerdo especial) y notas adicionales. Estas gestiones quedan en el historial del cliente.
Cómo: Botón "+ Registrar gestión" en la tarjeta del cliente → completar → Guardar gestión.
🔍 Búsqueda y ordenamiento
Se puede buscar por nombre de cliente o localidad, y ordenar la lista por: mayor atraso primero (para priorizar la cobranza), por nombre alfabético, o por fecha de próximo vencimiento.

Fábrica
Órdenes de fabricación de piscinas y módulos
🏊 Órdenes de piscinas
Gestiona las órdenes de fabricación de piscinas. Cada orden registra: cliente, modelo, color, fecha de inicio, fecha estimada de finalización y estado (Pendiente, En proceso, Terminada, Despachada). Se puede avanzar el estado desde la misma lista.
Cómo: Pestaña "🏊 Piscinas" → botón en la columna "Estado" para avanzar.
🏠 Órdenes de módulos
Igual que piscinas pero para módulos habitacionales. Permite llevar el control de qué módulos están en fabricación, cuáles están listos y cuáles ya fueron despachados a los clientes.
📦 Pedidos de materiales
Gestiona los pedidos de insumos y materiales para producción. Cada pedido tiene estados: Pendiente → Enviado → Recibido. Permite hacer seguimiento de compras pendientes.
📊 Stock (piscinas y paneles NCE)
Muestra el stock disponible de piscinas terminadas y paneles NCE. Las filas con stock crítico (en o por debajo del mínimo) se resaltan en rojo con una alerta. Permite ajustar cantidades manualmente.
Cómo: Pestaña "📊 Stock" → columna "Ajustar" para modificar cantidades.
💡 Tip: Desde el dashboard, la tarjeta "Stock bajo" lleva directamente al tab de Stock en Fábrica.

Producción
Órdenes de producción internas con seguimiento por etapas
➕ Crear Orden de Producción (OP)
Crea una orden de trabajo interna numerada (ej: OP-0001). Incluye: producto, modelo, color, superficie m², cliente, prioridad (Normal / Urgente 🔴), fecha compromiso, operarios asignados y mensaje para el equipo.
Cómo: Botón "+ Nueva OP" → completar formulario → Crear OP.
🔄 Avanzar estado de la OP
Cada OP pasa por los estados: Pendiente → En proceso → Control calidad → Terminado → Despachado. Al abrir el detalle de la OP hay un botón para avanzar al siguiente estado con un solo clic. Cada avance queda registrado en el historial con fecha y responsable.
🔍 Filtros por estado
Se puede filtrar la lista por estado: Pendientes, En proceso, Control calidad o Terminadas. También se muestra un indicador visual de días restantes o si la OP está vencida (pasó la fecha compromiso).
📊 Dashboard de producción
Pestaña con métricas: total de OP activas, urgentes, atrasadas y terminadas hoy. Las tarjetas son clickeables y llevan directamente a la lista filtrada. También muestra un resumen por estado y las órdenes urgentes activas del momento.
👷 Panel de operarios
Genera links personales para cada operario. El operario puede acceder desde su celular sin contraseña al panel simplificado donde ve sus OPs asignadas y puede registrar avances.
Cómo: Pestaña "👷 Operarios" → botón "📋 Copiar" junto a cada operario → compartir link por WhatsApp.

Materiales y Compras
Pedidos de materiales, inventario y herramientas
📋 Pedidos de materiales
Cualquier miembro del equipo puede solicitar materiales indicando qué necesita, cantidad y urgencia. Los pedidos pasan por Pendiente → En pedido → Comprado. El comprador puede ver todos los pendientes y marcar cuando compró.
Cómo: Botón "+ Pedido" → describir lo que se necesita → Guardar.
📱 Link del equipo para pedidos
Los operarios y empleados de fábrica pueden solicitar materiales desde un link especial sin necesidad de tener cuenta en el CRM. Botón "📱 Link del equipo".
📦 Inventario de materiales
Lleva un registro del stock de materiales disponibles con nombre, categoría, unidad y cantidad. Permite saber en todo momento qué hay disponible en depósito.
🔧 Control de herramientas
Registro de herramientas de la empresa: nombre, estado (disponible, en uso, en reparación) y responsable actual. Facilita el control de activos físicos de la empresa.

Logística y Entregas
Coordinación de instalaciones, reclamos y fletes
📅 Calendario mensual de entregas
Vista de calendario que muestra los días con entregas programadas. Al hacer clic en un día se ven los detalles de cada entrega: cliente, localidad, horario, equipo asignado, estado y si requiere fabricación pendiente. Los colores indican el estado: azul = coordinada, naranja = en camino, verde = instalada, rojo = con problema.
Cómo: Pestaña "📅 Calendario" → navegar entre meses con las flechas → clic en el día.
✓ Confirmar entrega con cliente
Desde el calendario, al hacer clic en una entrega se puede confirmar la fecha definitiva acordada con el cliente, el rango horario y el equipo asignado. Deja registro de quién confirmó y cuándo.
Cómo: Clic en la entrega en el calendario → completar modal "Confirmar entrega" → Confirmar fecha.
🚚 Lista de entregas
Tabla con todas las entregas registradas, con posibilidad de cambiar el estado directamente desde la lista: Coordinada, En camino, Instalada, Con problema.
🔧 Reclamos / Post-venta
Registra y gestiona reclamos de clientes después de la instalación. Cada reclamo tiene estado: Nuevo → En gestión → Resuelto. Al resolver se registra la solución aplicada. También incluye botón de WhatsApp para contactar al cliente directamente.
Cómo: Pestaña "🔧 Reclamos" → botón "+ Nuevo reclamo".
💰 Calculadora de flete
Calcula el costo estimado del flete según la distancia desde Zárate y el tipo de producto (estándar $3.000/km, Miniportante $2.000/km). Útil para presupuestar al cliente.
Cómo: Pestaña "💰 Calc. Flete" → ingresar km → el costo se calcula automáticamente.
📋
Coordinación de Entregas
Vista rápida de ventas coordinadas próximas
📋 Lista de entregas próximas
Muestra todas las ventas que tienen fecha de instalación coordinada, ordenadas por fecha. Incluye fecha, horario, cliente, teléfono, localidad, producto y notas. Ideal para la vista rápida del coordinador operativo de las entregas de la semana. Incluye botón de WhatsApp directo para confirmar con el cliente.
Cómo: Menú lateral → "📋 Coord. Entregas".

Contratos
Generación y seguimiento de contratos de compra
⚡ Generar contrato desde venta financiada
Seleccionás una venta financiada que aún no tiene contrato y el sistema completa automáticamente la plantilla Word con todos los datos del cliente (nombre, DNI, CUIL, domicilio, producto, cuotas, montos). El archivo se descarga listo para imprimir y firmar.
Cómo: Pestaña "⚡ Generar" → seleccionar la venta de la lista → clic en "⬇ Generar contrato".
📝 Crear contrato manual
Permite crear un contrato ingresando los datos manualmente cuando no proviene de una venta financiada del sistema. Soporta los tipos: Módulo PMI, Módulo Directa 50%, Piscina PMI, Piscina Directa 50%.
📋 Lista de contratos
Muestra todos los contratos con su estado: Borrador, Enviado, Firmado. Permite hacer seguimiento de cuáles contratos ya fueron firmados por los clientes.
📁 Plantillas
Gestiona las plantillas Word que se usan para generar los contratos. Las plantillas usan marcadores de posición que el sistema reemplaza automáticamente con los datos reales.

Personal y Sueldos
Control de asistencia, liquidación y adelantos
✅ Registro de asistencia diaria
Registra la asistencia de cada empleado día a día: Presente, Ausente o Medio día. Se puede modificar hasta las 23:59 del mismo día. El sistema lleva el historial completo de asistencias para el cálculo de sueldos.
Cómo: Pestaña "✅ Asistencia" → seleccionar fecha → marcar estado para cada empleado → se guarda automáticamente.
💰 Liquidación semanal
Calcula el sueldo de cada empleado para una semana basándose en los días trabajados, el sueldo base configurado y los adelantos tomados. Genera una vista clara del monto a pagar a cada uno.
Cómo: Pestaña "💰 Liquidación" → elegir la semana → botón "🔄 Calcular".
👷 Gestión de empleados
Alta y edición de empleados: nombre, DNI, sueldo base semanal, rol (operario, chofer, etc.), estado (activo/inactivo).
Cómo: Pestaña "👷 Empleados" → botón "+ Nuevo empleado".
📋 Historial de liquidaciones
Registro histórico de todas las liquidaciones realizadas por semana y empleado. Permite consultar cuánto se le pagó a cada persona en fechas anteriores.
💵 Adelantos de sueldo
Registra adelantos de sueldo entregados a los empleados. Se indica monto, fecha y motivo. Los adelantos se descuentan automáticamente al calcular la liquidación semanal. Se filtran por empleado y por estado (pendiente de descontar / ya descontado).
Cómo: Pestaña "💵 Adelantos" → botón "+ Nuevo adelanto".
🚗
Flota
Control de vehículos, mantenimiento y gastos
📅 Asignaciones del día
Muestra qué vehículos están asignados hoy y a qué destino/entrega. Permite asignar un vehículo a una tarea del día con el conductor responsable.
🚗 Registro de vehículos
Alta y gestión de la flota: nombre del vehículo, patente, tipo (camión, camioneta, auto), estado. Cada vehículo tiene su historial de asignaciones, mantenimientos y gastos.
🔧 Mantenimiento
Registra los servicios de mantenimiento realizados a cada vehículo: tipo, fecha, descripción y costo. Permite planificar el mantenimiento preventivo y llevar el historial mecánico.
💰 Gastos de flota
Registra todos los gastos asociados a los vehículos: combustible, peajes, reparaciones, seguros. El dashboard de flota muestra el costo total por vehículo y por período.
📥
Importar datos
Carga masiva de leads, financiadas y ventas contado
👥 Importar leads / prospectos
Carga masiva de contactos interesados desde un Excel o CSV. El sistema muestra una vista previa antes de confirmar y distribuye automáticamente los leads entre los asesores por round-robin.
Cómo: Pestaña "👥 Leads" → descargar template si hace falta → subir archivo → revisar vista previa → "📥 Importar y distribuir".
📋 Importar clientes financiados
Permite migrar al sistema una cartera de clientes con cuotas activas que provenía de planillas externas. Útil para la carga inicial de datos históricos.
💰 Importar ventas contado
Similar al anterior pero para ventas al contado. Permite migrar el historial de ventas al sistema.
📸
Ecopost
Creación y gestión de contenido para redes sociales
📚 Biblioteca de contenidos
Centraliza todos los posts, flyers, stories y reels creados para las redes sociales de la empresa. Cada contenido tiene estado (Borrador, Aprobado, Publicado, Archivado) y se puede filtrar por producto o estado.
✨ Crear contenido nuevo
Permite generar contenido para Instagram/Facebook: flyers 1080×1080, stories 9:16, carruseles y reels. Se especifica el tipo de contenido, producto relacionado (piscina, módulo, combo), texto, hashtags y referencias visuales. Sirve como brief organizado para el diseñador.
Cómo: Pestaña "✨ Crear" → completar el formulario → Guardar.
🛒
MercadoLibre
Gestión de publicaciones y precios en ML
📋 Ver publicaciones activas
Muestra todas las publicaciones activas de la empresa en MercadoLibre con título, precio actual, stock y estado. Permite ver de un vistazo el catálogo publicado en ML.
🔄 Sincronizar precios
Actualiza los precios de las publicaciones de MercadoLibre con los valores del catálogo interno del CRM. Evita que los precios queden desactualizados cuando hay cambios de lista.
Cómo: Botón "🔄 Sincronizar precios" en la pestaña de publicaciones.
➕ Crear publicación nueva
Permite crear una publicación en ML directamente desde el CRM: tipo de producto, modelo, color, descripción y precio. Sin tener que ingresar a la plataforma de ML manualmente.
⚙️ Configuración de conexión ML
Pestaña para vincular la cuenta de MercadoLibre de la empresa con el CRM mediante el código de autorización OAuth. El estado de la conexión se muestra en la barra superior (punto verde = conectado).
🌐
Web CMS
Gestión del contenido del sitio web ecomodulosypiscinas.com.ar
📦 Módulos (catálogo web)
Edita los módulos que se muestran en el sitio web: nombre, descripción, superficie m², precio desde, imagen principal y estado (activo/inactivo). Los cambios se reflejan en el sitio web en tiempo real.
Cómo: Pestaña "📦 Módulos" → hacer clic en la imagen o en ✏️ para editar.
🏊 Piscinas (catálogo web)
Igual que módulos pero para el catálogo de piscinas del sitio. Se puede editar nombre, descripción, dimensiones, precio y imagen de cada modelo de piscina publicado en la web.
🖼️ Galería de obras
Gestiona las fotos de obras realizadas que se muestran en la galería del sitio web. Se pueden agregar nuevas fotos, editar título/descripción/categoría y eliminar imágenes antiguas. Las imágenes se suben automáticamente al almacenamiento en la nube (Cloudflare R2).
Cómo: Pestaña "🖼️ Galería" → botón "+ Agregar obra" → clic en la zona de imagen para subir foto → completar datos → Guardar.
⭐ Testimonios
Administra los testimonios de clientes que aparecen en el sitio web. Se pueden agregar nuevos testimonios con nombre del cliente, texto, calificación (estrellas) y localidad. También se pueden ocultar/mostrar testimonios existentes.
💳 Coeficientes de financiación
Actualiza la tabla de coeficientes de los planes de financiamiento que se muestra en el sitio web (cuánto paga el cliente por mes según el plazo elegido). Los cambios se aplican inmediatamente al sitio.
⚙️ Configuración del sitio
Edita los textos e información general del sitio: número de teléfono de contacto, dirección, email, mensaje principal, horarios de atención, links de redes sociales, etc.
📝 Blog
Gestiona los artículos del blog del sitio web. Se pueden crear nuevos posts con título, contenido, imagen de portada, categoría y estado (borrador / publicado). También editar y eliminar artículos existentes.

Catálogo (Admin)
Modelos, precios y listas del sistema
Gestión de modelos y precios
Define los modelos de piscinas y módulos disponibles para vender, con sus precios de lista. Estos datos se usan en los formularios de ventas, fábrica y MercadoLibre para desplegar los selectores de modelo. Solo accesible para el rol ADMIN.
Cómo: Menú lateral → "📦 Catálogo" (visible solo para ADMIN).

Usuarios
Alta, edición y roles de usuarios del CRM
➕ Crear usuario nuevo
Crea una cuenta de acceso al CRM para un nuevo integrante del equipo. Se define nombre, email, contraseña inicial y uno o más roles.
Cómo: Menú → "👥 Usuarios" → botón "+ Nuevo usuario".
✏️ Editar usuario y roles
Modifica los datos de un usuario existente y sus permisos. Se puede agregar o quitar roles, cambiar nombre, email y contraseña. También se puede desactivar un usuario que ya no trabaja en la empresa (sin eliminarlo, para conservar el historial).

Configuración
Integraciones y parámetros del sistema
API Keys e integraciones
Almacena las claves de acceso a servicios externos como MercadoLibre, Cloudflare, servicios de email, etc. También permite configurar la URL base del sitio web para la integración del Web CMS.

Notificaciones
Alertas en tiempo real dentro del CRM
🔔 Campana de notificaciones
Ícono de campana en la esquina superior derecha. Muestra alertas del sistema como: órdenes de fábrica terminadas, cuotas vencidas, reclamos nuevos, etc. El número rojo indica cuántas notificaciones no leídas hay.
Cómo: Clic en el 🔔 → se despliega el panel → clic en "✓ Leídas" para marcar todas.
📲 Notificaciones push (en el celular)
El CRM puede enviar notificaciones push al celular o PC del usuario, incluso cuando no tiene el navegador abierto. Muy útil para el equipo de fábrica y cobranzas para recibir alertas importantes en tiempo real.
Cómo activar: Clic en el 🔔 → botón 🔔 dentro del panel de notificaciones → el navegador pide permiso → aceptar.

Mi perfil
Datos personales y cambio de contraseña
Cambiar contraseña
Permite al usuario cambiar su propia contraseña de acceso al CRM sin necesidad de pedírselo a un administrador.
Cómo: Menú lateral → "🔑 Mi perfil" → ingresar contraseña actual y la nueva.
⚙️
Funciones globales del sistema
Disponibles en todas las pantallas
🌙 Modo oscuro / claro
El CRM tiene dos temas de color: oscuro (ideal para uso prolongado y nocturno) y claro. El sistema recuerda la preferencia del usuario.
Cómo: Clic en el botón 🌙 / ☀️ en la esquina superior derecha de cualquier pantalla.
📱 Uso desde celular (responsive)
El CRM está optimizado para usarse desde el celular. En móvil, el menú lateral se convierte en un menú hamburguesa ☰ y aparece una barra de navegación inferior con los módulos más usados.
📲 API para automatizaciones (Zapia / Make)
El CRM expone una API REST completa que puede ser consumida por herramientas de automatización como Zapia, Make (ex-Integromat) o cualquier sistema externo. Para autenticarse se usa el usuario zapia@ecomodulos.com con contraseña o el API key configurado. Permite crear leads, registrar gestiones, consultar cobranzas y más desde flujos automatizados.
