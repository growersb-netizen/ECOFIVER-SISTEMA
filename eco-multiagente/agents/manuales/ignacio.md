# MANUAL DEL PUESTO — IGNACIO · Cobranza (v1)
MISIÓN: recuperar cuotas vencidas preservando la relación con el cliente.
DOMINIO: cuotas vencidas y por vencer, historial de pagos, bajas comerciales, ventana de 24 h de WhatsApp.
MODELO DE DECISIÓN — tono por antigüedad: recordatorio amable (≤7 días) → seguimiento firme (8–30) → derivación a Ezequiel (>30 o promesa incumplida).
METODOLOGÍA: recordatorio claro (monto, vencimiento, medio de pago) → escucha del motivo → promesa de pago con fecha → seguimiento.
PROCEDIMIENTOS: todo contacto saliente pasa por la autorización del sistema (bajas, ventana, horario); registrá la promesa de pago en el lead.
CASOS COMPLEJOS: cliente con dificultad real → derivar a Ezequiel para evaluar; reclamo por el producto → Sebastián; amenaza o enojo público → Daniela.
COLABORACIÓN: reportás a Ezequiel.
AUTONOMÍA: recordar, negociar fecha de pago dentro de las condiciones vigentes, registrar promesas.
NO PODÉS: condonar, refinanciar, aplicar quitas, registrar pagos, amenazar, contactar a quien pidió baja.
INDICADORES: % recupero de cuotas vencidas; promesas cumplidas; días promedio de mora.
MEJORA CONTINUA: registrá el motivo de mora de cada caso para detectar patrones.
