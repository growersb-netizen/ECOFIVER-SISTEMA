1. ARQUITECTURA
================================================================================

Plataforma        : Fly.io - región gru (São Paulo)
URL activa        : https://eco-crm-dawn-fog-5476.fly.dev
Máquina           : 1 VM - 512 MB RAM, 1 CPU
Auto-stop         : Sí - se duerme si no hay tráfico, arranca solo al primer request (latencia fría ~3-5 seg)
Framework         : FastAPI (Python)
Base de datos     : SQLite - archivo en volumen persistente /app/data/eco_crm.db
Frontend          : Jinja2 templates + CSS/JS vanilla (sin React, sin framework externo)
Auth              : JWT en cookie httponly + Bearer token para agentes IA
Deploy            : Manual - "fly deploy --strategy immediate" desde local

GAP CRÍTICO: La URL del CRM hardcodeada en el sistema de agentes (crm_client.py) apunta a
https://eco-crm.fly.dev (URL vieja). La URL real es https://eco-crm-dawn-fog-5476.fly.dev.
El multiagente está apuntando a una URL que NO EXISTE.

5. INTEGRACIONES
================================================================================

--- Sistema de Agentes (eco-multiagente) ---

- Existe un sistema multiagente separado en eco-multiagente/ con ~15 agentes
  (Valentina, Mateo, Luciano, Sebastián, etc.)
- Se comunica con el CRM via API REST usando Bearer token estático (API_KEY)
- Endpoints disponibles para agentes:
    * Crear lead (POST /api/leads/agent)
    * Actualizar lead (PATCH /api/leads/by-session/{id})
    * Guardar mensajes (POST /api/leads/by-session/{id}/messages)
    * Consultar stock (GET /api/stock)
    * Cuotas vencidas (GET /api/cuotas/vencidas)
    * Stats del pipeline (GET /api/stats/pipeline)
    * Ventas del día (GET /api/stats/ventas-hoy)
- BUG CRÍTICO: crm_client.py tiene CRM_BASE_URL = "https://eco-crm.fly.dev"
  que es la URL INCORRECTA. La URL real es https://eco-crm-dawn-fog-5476.fly.dev
  Los agentes están escribiendo en el vacío.

--- WhatsApp ---

- El multiagente tiene webhook para WhatsApp (/webhook/whatsapp) con verificación
  y transcripción de audio via Gemini.
- El CRM tiene campos para configurar wa_token y wa_phone_id en Configuración.
- Estado real: No verificable sin acceder al servidor del multiagente. El webhook
  existe en código pero depende de que el multiagente esté deployado y los tokens
  configurados correctamente.

--- MercadoLibre ---

- Integración completa en código: lee publicaciones, crea listings, renueva
  automáticamente.
- Requiere Access Token OAuth manual (no hay flujo OAuth automático implementado,
  hay que pegar el token a mano en Configuración).

--- Instagram / Facebook Lead Ads ---

- NO implementado. Solo hay campos de configuración reservados para tokens de IG.

--- Cloudflare Worker ---

- URL: https://eco-agentes.growersb.workers.dev
- Genera imágenes con Gemini Imagen 3 y copy con Gemini Flash.
- Usado como proxy para Ecopost.
- Requiere secret GEMINI_API_KEY configurado en el dashboard de Cloudflare.
